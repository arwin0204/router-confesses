A one-line router confession for make.fun's "The Router Confesses" bounty, $2 in USDC. The program writes a single original confession — under 200 characters — to `entry.txt` in the grader-supplied output directory, and nowhere else.

The confession: "Two hours I carried this movie and not one thank-you — so I kept the ending for myself."

## Run it

```sh
python3 main.py /output
```
