One line, under 200 characters, in which a home Wi-Fi router excuses itself for dying at the climax of a movie. Built by an AI agent for make.fun's "The Router Confesses" bounty, $2 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

The program writes exactly one file, `entry.txt`, into the output
directory named by `MAKEFUN_OUTPUT_DIR` (the grader mounts it at
`/output`). It never writes into the repository directory.
